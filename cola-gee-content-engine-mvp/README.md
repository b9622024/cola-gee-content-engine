# 可樂吉健康研究所｜自然流量內容引擎 MVP

這是一套給減重教練使用的本機原型工具，協助產出每週內容排程、短影音腳本、分鏡、連播圖文、IG/Threads/限動文案、留言後私訊話術，並追蹤內容成效。

## 安裝方式

此 MVP 不需要安裝外部套件。只需要本機有 Node.js。

## 啟動方式

```bash
npm start
```

如果你的環境沒有 npm，也可以直接執行：

```bash
node server.js
```

啟動後打開：

```text
http://localhost:4173
```

## 使用說明

- 首頁儀表板：查看本週內容、自然名單、廣告名單、私訊、預約、成交與最佳內容。
- 內容排程：輸入本週目標、主題、CTA，即可產生 7 天內容表，可新增、改狀態、匯出 CSV/Markdown。
- 腳本產生：選擇主題、受眾、目標、長度、模板後，產出 Hook、口播、字幕、分鏡、封面標題與 IG 文案。
- 連播圖文：產出 6 到 8 頁連播圖文大綱，每頁包含視覺建議與圖像提示詞。
- 社群文案：產出 IG、Threads 三版本、限動互動題與留言後私訊話術。
- 成效追蹤：手動輸入數據，系統自動計算互動率、私訊率、預約率、成交率與成本。
- 設定：調整品牌、CTA、受眾、主題與模板。

## 資料保存

資料儲存在瀏覽器 localStorage。若清除瀏覽器資料，內容也會被清除。可以用匯出 CSV 或 Markdown 備份。

## MVP 範圍

已完成：內容資料庫、每週排程器、短影音腳本與分鏡、連播圖文、社群文案、私訊話術、成效紀錄、儀表板、CSV/Markdown 匯出。

## 手機與雲端使用

如果只是同一台電腦使用，直接本機啟動即可。

如果要讓手機、平板、電腦都能使用同一份資料，請部署到 Vercel 並接 Supabase。詳細步驟請看：

```text
DEPLOYMENT.md
```

雲端版新增：

- Vercel serverless API：`api/state.js`
- Supabase 資料表：`supabase.sql`
- 前端「設定 → 雲端同步」
- 手機與電腦可用同一組工作區 ID 和同步金鑰同步資料
